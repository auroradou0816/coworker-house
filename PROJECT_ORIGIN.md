# CoWorker House provenance

CoWorker House is maintained by Yijia Dou and is derived from
[Skymore/roomtalk](https://github.com/Skymore/roomtalk). The upstream author
authorized Yijia Dou to modify and publish this derivative project.

The imported 738-commit history has been rewritten to use Yijia Dou as author
and committer and to update brand names in commit messages. Original commit
dates, parent relationships and file trees were preserved. This administrative
rewrite does not imply that Yijia Dou originally authored the upstream changes.
Upstream snapshot: `ca5af16` (full mapping and original bundle backed up locally).

New commits record changes made for CoWorker House, including the frontend
redesign and branding. Existing third-party license and copyright notices
remain applicable and are retained. No new repository-wide license is assigned
by this migration.

Legacy Fly.io configuration and deployment workflow files were removed from the
current source tree. The repository deploys to its own Lightsail instance using
the current [Deployment Guide](DeploymentGuide.md).
